# Excalidraw Radial Menu

Круговое (pie) меню инструментов Excalidraw, которое всплывает **прямо под курсором** по одной
горячей клавише. Сделано под графический планшет: нажал кнопку на пере → повёл в сторону →
отпустил. Ни одного похода к тулбару наверху.

</p>

* Выбор **по направлению**, а не по попаданию: достаточно мазнуть пером в сторону сектора —
  курсору не нужно попадать точно в кольцо.
* Мёртвая зона в центре = отмена.
* **Цвет одним жестом**: задержались на секторе рисующего инструмента — кольцо схлопывается в
  центр, оттуда расцветает палитра. Отпустили на цвете — получили и инструмент, и цвет.
  Вернулись в центр — шаг назад, к инструментам.
* **Инструмент перестаёт сбрасываться** на «Выделение» после каждой фигуры.
* Работает с клавиатуры, с кнопки пера и с правой кнопки мыши.
* Меню подхватывает тему и акцентный цвет самого Excalidraw.
* Полностью настраиваемый состав: 2–14 пунктов из 23 действий плюс свои цвета.
* Настраивается прямо на колесе: клик по сектору меняет содержимое, перетаскивание — порядок.
* В комплекте английский и русский; добавить язык — это один JSON-файл.

## Установка

1. `chrome://extensions` → включить **Режим разработчика** (справа сверху).
2. **Загрузить распакованное расширение** → выбрать папку `excalidraw-radial-menu`.
3. Открыть <https://excalidraw.com/> и нажать горячую клавишу.

Готовый архив лежит в [Releases](../../releases): скачать zip, распаковать и загрузить папку тем
же способом. Chrome ставит подписанные `.crx` только из Web Store, поэтому распакованная папка —
рабочий путь.

Настройки: иконка расширения на панели Chrome, либо `chrome://extensions` → *Подробнее* →
*Параметры расширения*.

## Горячая клавиша и перо

По умолчанию — **Caps Lock**. Назначьте в драйвере планшета эту же клавишу на кнопку пера
(для Huion: *Настройки пера → Клавиша → Нажатие клавиш*).

Важный нюанс: **на macOS Chrome присылает Caps Lock через раз** — нажатие «включения» приходит
как `keydown`, «выключения» как `keyup`. Расширение это учитывает, и схема «нажал — открылось,
нажал ещё — выбрал» работает. А вот «зажал-отпустил» с Caps Lock на macOS невозможна в принципе:
браузер не сообщает об удержании.

Если хотите именно удержание, назначьте на перо любую другую клавишу и укажите её в настройках
кнопкой захвата. Клавиши, которые Excalidraw не использует:

| Клавиша | Замечание |
|---|---|
| `` ` `` | свободна, рядом с большим пальцем |
| `F13`–`F19` | вообще ни с чем не конфликтуют, если драйвер их умеет |
| `Alt` + `Q`, `Alt` + `W` | безопасная комбинация, если свободных клавиш нет |
| правый `Shift` / правый `Alt` | ловятся отдельно от левых |

Захват понимает и модификаторы: нажмите комбинацию целиком.

## Мышь

Без планшета то же меню работает на кнопке мыши: **Настройки → Как выбирать → Открывать кнопкой
мыши**. Нажал, мазнул, отпустил — либо кликнул и выбрал вторым кликом.

Пока это включено, выбранная кнопка заменяет собой родное контекстное меню Excalidraw.

## Режимы выбора

| Режим | Поведение |
|---|---|
| **Авто** (по умолчанию) | Держите дольше ~0.2 с — выбор по отпусканию. Быстрый тап — меню остаётся висеть, выбираете тапом, цифрой или буквой. |
| **Удержание** | Меню живёт строго пока клавиша зажата. |
| **Переключатель** | Первое нажатие открывает, второе выбирает. |

При открытом меню: `Esc` — отмена, `1`–`9` — выбор по номеру сектора, буква инструмента
(`R`, `O`, `T`…) — прямой выбор.

## Цвет

Задержитесь пером на секторе карандаша, прямоугольника, эллипса, ромба, стрелки, линии или
текста, **не отпуская клавишу**, — по краю сектора побежит дуга, и через 350 мс кольцо
инструментов схлопнется в центр, а оттуда расцветёт палитра. Дальше как обычно: мазнули в
сторону цвета, отпустили. Применятся сразу оба.

* Дуга показывает, у каких секторов есть палитра и сколько осталось держать.
* Пока перо движется, отсчёт сбрасывается — случайно провалиться в палитру не выйдет.
* **Вернулись в центр — палитра схлопывается обратно в инструменты**, ничего не применяется.
* Отпустили в центре палитры — применится только инструмент, цвет останется прежним.
* `Esc` — отмена целиком.

В настройках задаётся своя палитра (2–14 цветов, любой hex), задержка до её появления
(0 — выключить подменю) и что именно менять: цвет обводки или цвет фона.

Цвета можно класть и прямо в основное колесо, наравне с инструментами — они есть в списке
«что положить» у каждого сектора.

## Чтобы инструмент не сбрасывался

По умолчанию Excalidraw после каждой фигуры возвращается к «Выделению», и это бесит, когда нужно
подряд пять стрелок. **Настройки → Как выбирать → Не сбрасывать инструмент после рисования**
включает штатный «замок» Excalidraw при каждом выборе из колеса. Расширение замок только
включает и никогда не выключает, так что вашему ручному переключению не мешает.

## Настройка колеса

Всё правится прямо на превью:

* **клик по сектору** — выбрать, что в нём лежит (любой инструмент или цвет из палитры);
* **перетаскивание сектора** — поменять порядок;
* **«+ добавить сектор»** — новый пункт;
* кнопка **«показать палитру»** переключает превью на кольцо цветов: там клик по сектору
  открывает выбор цвета, перетаскивание меняет порядок.

## Что можно положить в колесо

Инструменты: карандаш, ластик, выделение, лассо, рука, прямоугольник, ромб, эллипс, стрелка,
линия, текст, изображение, фрейм, лазер, заливка, «в фигуру», web-вставка.
Действия: отменить, вернуть, удалить, дублировать, сгруппировать, вписать всё.
Плюс любые цвета из вашей палитры.

## Языки

Все видимые строки лежат в `_locales/<язык>/messages.json`, по умолчанию `en`. Чтобы добавить
язык, скопируйте `_locales/en` в `_locales/<язык>`, переведите значения `message` и перезагрузите
расширение — Chrome сам возьмёт папку под язык интерфейса браузера. Больше ничего трогать
не нужно.

## Как это устроено

Расширение не лезет во внутренности Excalidraw и не патчит его состояние.

**Инструменты.** В `document` уходят ровно те же `KeyboardEvent`, которые сгенерировала бы
настоящая клавиатура, — Excalidraw переключает инструмент своим штатным обработчиком. Текущий
инструмент читается из `[data-testid^="toolbar-"][aria-pressed="true"]`. Лассо и web-вставка
горячих клавиш не имеют — для них расширение открывает выпадашку «ещё» и жмёт пункт само.

**Цвет.** В левой панели свойств находится нужный ряд (`.color-picker-container`: «Обводка»
опознаётся по top-pick `#1e1e1e`, «Фон» — по `transparent`), кликом по его триггеру открывается
штатный попап, в его hex-поле пишется цвет, и попап закрывается повторным кликом. На эти ~50 мс
попап скрыт инжектнутым стилем, поэтому мигания не видно. `Escape` для закрытия не используется:
он заодно сбрасывает инструмент на «выделение». Так работает любой hex, а не только пять
стандартных top-picks.

**Тема** берётся из класса `theme--dark` и CSS-переменных `--color-primary` /
`--island-bg-color` на контейнере `.excalidraw`.

```
manifest.json            манифест MV3
_locales/<язык>/         все видимые строки
src/common.js            инструменты, иконки, геометрия колеса, стили (общее для меню и настроек)
src/content.js           content-скрипт: горячая клавиша, оверлей, выбор сектора, отправка событий
src/options.html/js/css  настройки с живым редактируемым превью
src/background.js        клик по иконке → открыть настройки
dev/                     локальный стенд для отладки, в расширение не входит
```

### Локальная отладка

```bash
python3 dev/serve.py          # http://127.0.0.1:8899
```

`dev/index.html` — макет Excalidraw (тулбар, панель цвета, лог событий) с заглушкой `chrome.*`,
`dev/options.html` — страница настроек вне расширения. К обеим можно добавить `?lang=ru`, чтобы
проверить перевод. Пересобрать вторую после правки `src/options.html`:

```bash
sed -e 's#href="options.css"#href="../src/options.css"#' \
    -e 's#src="common.js"#src="../src/common.js"#' \
    -e 's#src="options.js"#src="../src/options.js"#' \
    -e 's#<link rel="stylesheet"#<script src="chrome-stub.js"></script>\n<link rel="stylesheet"#' \
    src/options.html > dev/options.html
```

## Своя копия Excalidraw

Добавьте её адрес в `manifest.json` — в `host_permissions` и в `content_scripts[0].matches` —
и перезагрузите расширение.
